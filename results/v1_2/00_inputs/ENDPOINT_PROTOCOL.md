# v1.2 endpoint protocol

Defined before interpreting v1.2 robustness results.

## Primary

1. DeepPBS per-protein competition Spearman and primary-six median.
2. Position-preserving permutation null.
3. Matched DeepPBS versus PBM-local comparison.
4. Position-level versus within-position substitution decomposition.
5. Leave-one-position-out robustness.

## Secondary

Pearson correlation, all-mutation null, top-quartile deleterious recovery, mutation jackknife, directionality applicability, frozen NA-MPNN-derived comparison, and DBP048 window sensitivity.

DBP048 is excluded from every primary-six summary. No metric, orientation, register, or window is selected using experimental correlation.
