# Data Request Email: RFdiffusion3

Subject: Request for designed DNA-binding protein specificity data for an independent benchmark

Dear authors,

We are conducting an independent benchmark of specificity prediction for de novo designed DNA-binding proteins. We have frozen our current development benchmark and intend to preregister the analysis before accessing quantitative labels.

Would you be able to share, if available, the following validation materials for the RFdiffusion3 DNA-binding protein study?

- experimentally tested protein construct sequences;
- corresponding intended DNA targets;
- randomized-library sequence definitions and randomized-region coordinates;
- sequencing counts and/or normalized specificity scores;
- quantitative variant-competition tables;
- assay, normalization and replicate metadata;
- mapping between design IDs and experimentally tested constructs.

The requested data would be used as an independent confirmatory cohort under a frozen analysis plan. We will not use it to select models, tune parameters, change scoring rules, or remove poorly performing proteins after label access. Results and failures would be reported transparently.

Thank you for considering this request.

Best regards,
The DBP specificity benchmark team
