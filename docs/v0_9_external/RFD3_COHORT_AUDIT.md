# RFdiffusion3 Cohort Audit

## Scope and firewall

This is a metadata-only audit. No candidate-level binding values, rankings, experimental labels, or model-comparison results were opened. The public bioRxiv abstract reports generation of 96 designs for each of 15 diverse DNA targets, specific binders for 7 targets, and follow-up variant-competition and randomized-library screening. These statements describe study design and reported scope, not validation labels.

## Answers to the preregistered questions

1. **How many constructs obtained sequence-specific validation?** Exact number of experimentally characterized protein constructs is not specified by the metadata inspected. “96 designs per target” is a generation count, not a tested-construct count.
2. **Randomized-library geometry?** The abstract states randomized-library screening but does not specify whether the library is fully random, target-centered, fixed-position mutagenesis, or the randomized-region length. This remains unverified.
3. **Independent profile per protein?** Not verified. The study-level description does not establish a complete quantitative profile for every generated design.
4. **Protein sequences public?** Not verified under the metadata-only audit.
5. **Exact experimental constructs public?** Not verified.
6. **Intended target DNA public?** Target campaigns are described, but exact validation-ready target records are not verified.
7. **Quantitative sequencing counts public?** Not verified; no count table was opened.
8. **Processed specificity scores public?** Not verified; no processed label table was opened.
9. **Accession/supplement/repository?** The bioRxiv DOI is recorded. No verified public accession or repository containing the required validation schema was identified in this metadata pass.
10. **Can data be downloaded and schema-inspected without labels?** Not established. Until a metadata-only archive or author-provided schema is confirmed, download is not attempted.

## Classification

RFdiffusion3 is an **UNEXPOSED_CONFIRMATORY_CANDIDATE**, provisionally Tier 2 because randomized-library specificity profiling is reported. It is not yet a usable cohort. Before any label access, the exact constructs, target mapping, randomized region, per-protein coverage, and raw/processed file schema must be verified and the validation plan frozen.

Source: `https://www.biorxiv.org/content/10.64898/2026.04.27.720408v1`.
