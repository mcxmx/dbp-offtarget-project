# v0.3.1 Scientific Audit

Audit date: 2026-09-01

Repository: https://github.com/mcxmx/dbp-offtarget-project

Scope: scientific audit and correction of the designed-DBP uPBM benchmark before any protein-conditioned model, DeepPBS, NA-MPNN, TransBind, or full-genome expansion.

## Starting State

- v0.3 collected GEO GSE237017 metadata and 12 uPBM samples for DBP1, DBP3, DBP5, DBP6, DBP9, DBP35, and DBP48.
- v0.3 parsed processed 7-mer E-score tables and recovered protein sequences and intended target sequences from official supplementary material.
- v0.3 produced replicate QC, sequence-only baseline tables, target-derived 7-mer rank summaries, and preliminary figures.
- v0.3 preserved raw GEO files under `data/raw/gse237017/`; v0.3.1 must not alter those files.

## Audit Findings To Correct

1. **Paper percentile definition mismatch risk.**
   v0.3 reported intended-target-derived overlapping 7-mer percentiles. The original paper reports designed binding-site motif percentiles in the uPBM landscape. These may not be the same definition.

2. **Target definition ambiguity.**
   v0.3 used `intended_target_dna` as a single field. For designed DBPs, at least three concepts must be separated: original design target, experimental assay target, and shorter binding-site motif used for PBM evaluation. DBP48 requires special attention because the paper discusses sequence C in addition to its original target I.

3. **Reverse-complement equivalence.**
   GSE237017 processed 7-mer files contain 8192 rows with two 7-mer columns. Expanding them produces 16384 oriented sequences, but dsDNA specificity has 8192 reverse-complement equivalence classes. v0.3 did not represent `canonical_7mer` explicitly.

4. **Independent unit overstatement.**
   Reporting 114688 protein-7mer rows without clarifying reverse-complement equivalence can overstate the number of independent sequence units. The correct distinction is 114688 oriented rows versus 57344 protein-RC-class units.

5. **Sequence-only baseline orientation handling.**
   v0.3 sequence-only baseline compared candidate 7-mers to target-derived 7-mers without formal reverse-complement-aware canonicalization.

6. **Disagreement count misinterpretation.**
   v0.3 `sequence_similarity_failure_candidates.csv` stored top examples generated by a per-protein `head(20)` truncation. The resulting 140 rows are example rows, not the total number of sequence-vs-experiment disagreement candidates.

7. **Replicate noise ceiling missing.**
   v0.3 computed replicate correlations but did not package them as an empirical assay reproducibility reference for future model comparisons.

8. **Protein and target non-independence.**
   The seven designed DBPs share design campaigns, protein sequence similarity, and target/motif groups. Future splits must not treat every protein or every row as fully independent.

9. **Natural-to-designed OOD confounding risk.**
   If future natural DBP training data use HT-SELEX and designed DBP external data use uPBM, a performance drop may include assay shift as well as protein distribution shift.

10. **Processed/raw terminology.**
    v0.3 benchmark scores come from GEO processed uPBM files, not raw array-level processing performed in this repository. v0.3.1 should use terms such as processed experimental uPBM E-score.

11. **Portability issue.**
    Long-term metadata should not preserve local machine absolute paths. v0.3.1 should provide a portable manifest with project-relative paths.

12. **Test coverage gaps.**
    v0.3 requires tests for RC equivalence, sample coverage, paper percentile reproduction, portable paths, provenance, and schema stability.

## Required Validation Gate

v0.4 model work is allowed only if v0.3.1 establishes:

- PBM parsing has no major issue.
- Published motif percentile reproduction is reasonable.
- Reverse-complement handling is explicit and tested.
- Target definitions are separated and documented.
- Disagreement counts are corrected.
- Tests pass.

Final gate labels: `GO TO V0.4`, `CONDITIONAL GO`, or `STOP -- FIX REQUIRED`.
